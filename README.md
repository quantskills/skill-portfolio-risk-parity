# skill-portfolio-risk-parity
This approach is adopted when constructing a portfolio where each asset contributes equally to the total portfolio risk (as opposed to equal weight allocation).

## Typical Application Scenarios

- Multi-asset allocation across equities, fixed income, commodities, and precious metals;
- Balanced portfolios requiring steady, low volatility;
- Multi-asset portfolios highly sensitive to correlation structures.

## Key Distinctions from Other Allocation Strategies

- Equal-weight (1/N) allocation: Assigns identical weights to all assets yet suffers severe risk concentration.
- Mean-variance optimization: Exhibits extreme sensitivity to expected returns and covariance matrices.

By contrast, risk parity relies solely on covariance matrices and delivers superior robustness.
